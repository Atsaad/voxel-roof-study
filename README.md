# Which roof type is this building?

A short perceptual study supporting a Master's thesis at the
**Technical University of Munich, Chair of Geoinformatics**.

Participants name the roof type of 3D building models. Some are real
buildings from open CityGML city data; others were produced by a
generative machine-learning model. Accuracy on the real buildings is the
benchmark — it shows how legibly a roof type can be read from this kind
of model at all — and the question is whether generated buildings are
as readable.

**Take part:** https://Atsaad.github.io/voxel-roof-study/

## Privacy

The page records only which option was chosen for each image, plus a
random number generated in the browser so that answers from one sitting
can be grouped. No name, email, account, cookie, free text, or
analytics. Nothing collected could identify a participant.

## Note on this repository

The study is blind: image filenames are hashes, and `stimuli.json`
lists the trials without labels. The mapping from image to roof type is
deliberately **not** in this repository.
